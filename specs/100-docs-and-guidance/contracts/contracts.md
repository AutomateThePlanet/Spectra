## C2 — Guard contracts

| `DocsRemovedConceptsGuardTests` | README.md, AGENTS.md, CONTRIBUTING.md, CLAUDE.md, docs/**/*.md minus historical list | a `RemovedConcept` match whose paragraph has no removal marker (and, for MCP, no legitimate-MCP name: BELLATRIX/Nova, Azure DevOps) |

| `SourceStringsGuardTests` | string literals in `src/**/*.cs` (excluding XML doc comments and `//` comments), bundled skill/agent/prompt `.md`, both `app.js` | a `RemovedConcept` match outside the explicit literal allow-list (legacy-key detection in `ConfigLoader`/`CriticConfig`, the internal `extract-criteria` progress phase id, negative statements to agents) |
| `CommandLineCheckTests` | synthetic lines | a known-good line fails or a known-bad line (`spectra ai generate`, `spectra ai analyze --extract-criteria`) passes |
| `ClaudeMdGuardTests` | CLAUDE.md | > 150 lines; a Commands line fails `CommandLineCheck`; a Project Structure folder is missing; a required heading is missing; Recent Changes contains `- ` list items |
